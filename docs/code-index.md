# ملحق 1: فهرس الفئات والدوال المساعدة (Code Class & Helper Index)

يوفر هذا الفهرس مرجعاً سريعاً لكافة الفئات البرمجية والدوال المساعدة المعرفة داخل المنصة بمحدداتها ومعاملاتها.

---

## 1. فئات النواة الأساسية (`App\Core`)

### فئة قاعدة البيانات (`App\Core\Database`)
* **`getInstance()`**:
  * *المعاملات*: لا يوجد.
  * *المخرجات*: `Database`.
  * *الوصف*: الحصول على كائن الاتصال المفرد بقاعدة البيانات.
* **`query($sql, $params = [])`**:
  * *المعاملات*: الاستعلام كـ نص، المعاملات كـ مصفوفة.
  * *المخرجات*: `PDOStatement`.
  * *الوصف*: تنفيذ استعلام مجهز آمن ضد الثغرات.
* **`fetch($sql, $params = [])`**:
  * *المخرجات*: `array|false`.
  * *الوصف*: جلب سطر واحد مطابق للاستعلام.
* **`fetchAll($sql, $params = [])`**:
  * *المخرجات*: `array`.
  * *الوصف*: جلب كافة الأسطر المطابقة للاستعلام.

### فئة موجه المسارات (`App\Core\Router`)
* **`add($route, $callback)`**: تسجيل مسار مخصص مع الدالة المنفذة له.
* **`dispatch()`**: تحليل مسار الطلب الحالي وتحويله للصفحة المناسبة أو عرض واجهة 404.

### فئة مدقق المدخلات (`App\Core\Validator`)
* **`validate($data, $rules)`**: فحص صحة مصفوفة البيانات بموجب القواعد المحددة.
* **`getErrors()`**: جلب قائمة الأخطاء المسجلة.

---

## 2. الدوال المساعدة المشتركة (Global Helper Functions)

### دوال الأمان والوقاية (`app/Helpers/security_helpers.php`)
* **`e($value)`**:
  * *المخرجات*: `string`.
  * *الوصف*: تنظيف النصوص وحجب رموز HTML للوقاية من ثغرات XSS.
* **`csrf_token()`**:
  * *الوصف*: توليد رمز مشفر عشوائي لحماية النماذج وحفظه في الجلسة.
* **`verify_csrf_token($token)`**:
  * *الوصف*: مطابقة الرمز المرسل مع الرمز المحفوظ بالجلسة للوقاية من CSRF.

### دوال الروابط والمسارات (`app/Helpers/url_helpers.php`)
* **`base_url($path = '')`**: تكوين الرابط المطلق للموقع استناداً لبيئة التشغيل.
* **`asset_url($path = '')`**: بناء الرابط المطلق لملفات الأصول (CSS/JS/Images).
* **`admin_url($path = '')`**: بناء الرابط المطلق لصفحات لوحة الإدارة.

### دوال النصوص العربية (`app/Helpers/text_helpers.php`)
* **`normalize_arabic($text)`**:
  * *الوصف*: إلغاء الهمزات والتشكيل وتوحيد الياء والتاء المربوطة لتسهيل فلاتر البحث والمطابقة.
* **`slugify($text)`**:
  * *الوصف*: تكوين روابط URL صديقة لمحركات البحث تدعم الكلمات العربية.
