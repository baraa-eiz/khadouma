# ملحق 1: سجل وتراخيص الصور الإيضاحية (Mock-up Image Source Index)

توثق هذه القائمة روابط الصور الإيضاحية وتراخيصها المستخدمة كبيانات تجريبية داخل النظام لضمان الامتثال القانوني الكامل وتجنب انتهاك حقوق النشر.

---

## 1. شروط استخدام الصور الإيضاحية في المنصة

* جميع الصور المدرجة أدناه هي صور تجريبية (Mock-ups) مأخوذة من خوادم عالمية تدعم ترخيص **المشاع الإبداعي الصفري (CC0 / Unsplash License)**.
* التراخيص المعتمدة تتيح استخدام الصور لأغراض تجارية وغير تجارية وتعديلها دون حاجة لذكر المصدر أو الحصول على موافقة خطية من المصور.
* يُوصى باستبدال هذه الصور بصور حقيقية للحرفيين وورش عملهم السورية فور انتقال المشروع لمرحلة الإنتاج والترويج الفعلي.
