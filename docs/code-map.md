# خارطة الأكواد والملفات الفنية (Project Code Map)

يوضح هذا الدليل تفاصيل توزيع الملفات البرمجية داخل المنصة ووظيفة كل ملف لتسهيل عمليات الإشراف والتطوير والمراجعة.

---

## 1. دليل ملفات الإعدادات والتشغيل الأساسي

* **`index.php`**: Front Controller. نقطة الدخول والمتحكم الرئيسي الذي يستقبل كافة الطلبات ويوجهها.
* **`config/config.php`**: ملف الإعدادات العام. يحتوي على ثوابت الاتصال والمجلدات وتحديد بيئة العمل (محلي XAMPP أو VPS).
* **`config/database.php`**: مخصص لإعداد معايير كائن PDO وخيارات الاتصال المجهزة وقواعد تشفير الاتصالات المتبادلة.
* **`includes/init.php`**: مهيئ ومحفز الإقلاع للبرنامج. يتولى تهيئة جلسات العمل (Sessions) والتحقق الأمني وتسجيل المترجم التلقائي للفئات (PSR-4 Autoloader).
* **`includes/auth.php`**: بوابة الأمان وبوابة التحقق من تسجيل دخول مدراء المنصة.
* **`includes/layout.php`**: منسق القوالب المشتركة. يدمج الترويسة والتذييل وملف الواجهة الفرعية المطلوبة.
* **`includes/header.php`**: الترويسة العامة. تشمل وسوم الـ HTML وشفرات التحميل والخطوط وبنية التصفح الرئيسية.
* **`includes/footer.php`**: تذييل الصفحات العام وروابط التواصل وحقوق الملكية للمنصة.

---

## 2. دليل مجلد النواة والمساعدين (`/app`)

يحتوي مجلد `app` على المنطق البرمجي والمنفصل للمنصة ويقسم كالتالي:

### أ. كود النواة الأساسي (`app/Core/`)
* **`Database.php`**: فئة إدارة كائن PDO المفردة (Singleton) ومحفز الاستعلامات المجهزة الآمنة.
* **`Router.php`**: الموجه الأساسي للمسارات العامة والصفحات الفرعية والصفحات التلقائية من قاعدة البيانات.
* **`Response.php`**: مسؤول عن تنظيم ترويسات الاستجابة وإعادة التوجيه (Redirect) وإخراج نصوص JSON.
* **`Validator.php`**: فئة فحص صحة المدخلات وخاصة الحقول الإجبارية وصيغ البريد الإلكتروني والأرقام السورية.

### ب. الدوال المساعدة المشتركة (`app/Helpers/`)
* **`security_helpers.php`**: دوال الهروب من وسوم HTML لمنع XSS وتوليد وفحص كود الـ CSRF.
* **`url_helpers.php`**: دوال بناء روابط المسارات، المجلدات والملفات الثابتة لتلافي تضارب روابط الصفحات.
* **`text_helpers.php`**: دوال تنظيف الحروف العربية وإلغاء الهمزات لتطابق نتائج البحث مع سلوك المستخدمين.
* **`seo_helpers.php`**: توليد وسوم العناوين والوصف للمساعدة في الأرشفة التلقائية بمحركات البحث.
* **`image_helpers.php`**: محرك توليد صور الـ SVG البديلة في المتصفح والتحقق من وجود الصور المرفوعة.

### ج. فئات مستودعات البيانات (`app/Repositories/`)
* **`AdminUserRepository.php`**: عمليات جلب بيانات مدراء المنصة وتحديث أوقات الدخول.
* **`SettingsRepository.php`**: تتبع وتحديث إعدادات الموقع العامة.
* **`ServiceRepository.php`**: مستودع تخصصات وخدمات الحرفيين وأعدادها النشطة.
* **`CityRepository.php`** & **`AreaRepository.php`**: مستودع تصفية المدن والأحياء.
* **`ProviderRepository.php`**: جلب بيانات الحرفيين المعتمدين، المتميزين وإحصائيات الحالات.
* **`ReviewRepository.php`** & **`ReportRepository.php`**: مستودع تتبع وإحصاء الشكاوى والتقييمات المعلقة.

---

## 3. دليل الواجهات العامة والإدارية

* **`pages/home.php`**: واجهة الزوار الرئيسية، محرك البحث، استعراض بطاقات الحرفيين وتصنيفات الخدمات.
* **`pages/not-found.php`**: واجهة الخطأ 404 المخصصة.
* **`pages/about-us.php`**, **`terms.php`**, **`privacy.php`**: الصفحات النصية القانونية والتعريفية المستدعاة ديناميكياً من قاعدة البيانات.
* **`admin/login.php`**: شاشة الدخول الإدارية الآمنة للمشرفين.
* **`admin/dashboard.php`**: لوحة متابعة إحصائيات وقراءات جداول المنصة المباشرة.
* **`admin/logout.php`**: إغلاق الجلسة وتدمير ملف الكوكي المخصص للمشرفين.
