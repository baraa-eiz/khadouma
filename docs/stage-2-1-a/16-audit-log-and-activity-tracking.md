# 16. Audit Log and Activity Tracking (سجل التدقيق وتتبع العمليات)

يوضح هذا المستند كيفية تتبع الأنشطة الإدارية وسجل نقرات الاتصال وبناء سجل أمان شفاف لعمليات المنصة.

---

## 1. سجل التدقيق الإداري (Administrative Audit Log)

يجب تدوين أي عملية تعديل، تفعيل، أو حذف للبيانات تتم بواسطة مديري النظام في جدول `audit_logs` لضمان الشفافية وإمكانية تتبع الأخطاء الأمنية أو البشرية.

### الحقول المسجلة في كل عملية:
* **`admin_id`**: معرّف المشرف الذي قام بالإجراء.
* **`action`**: نوع الإجراء المتخذ (مثل: `provider_verified`, `review_approved`, `provider_soft_deleted`, `settings_updated`).
* **`entity_type`** / **`entity_id`**: نوع الجدول المستهدف ورقم السجل المعدل (مثل: `providers` و رقم السجل `42`).
* **`before_value`** / **`after_value`**: حفظ الحقول قبل التعديل وبعده بصيغة JSON لمقارنة الاختلافات وتسهيل التراجع عن التعديل الخاطئ عند الحاجة.
* **`created_at`**: وقت حدوث العملية بالثانية.

---

## 2. تتبع اهتمامات الزوار ونقرات الاتصال (Contact Event Tracking)

لبناء إحصائيات دقيقة حول جدوى وأداء المنصة، والتعرف على المهن والمناطق الأكثر طلباً في سوريا، يقوم النظام بتسجيل نقرات الزوار على أزرار الاتصال الهاتفي أو النقر للانتقال لتطبيق WhatsApp.

### الحقول والبيانات المتتبعة:
* **`provider_id`**: معرّف الحرفي المستهدف بالاتصال.
* **`action_type`**: نوع الاتصال (`phone_call` أو `whatsapp_click`).
* **`city_id`** / **`service_id`**: حفظ بيانات المحافظة والخدمة الحالية بشكل صلب في نفس سجل الحدث لتسهيل الاستعلام الإحصائي السريع دون الحاجة لـ Joins معقدة ومكلفة مستقبلاً.
* **`user_ip`**: بصمة عنوان بروتوكول الإنترنت للزائر (مع تعتيم الأرقام الأخيرة للالتزام بالخصوصية) لحماية إحصائيات المنصة من التلاعب والنقرات الوهمية المكررة من نفس البصمة.
* **`created_at`**: وقت النقر الفعلي.

---

## 3. منطق الاستدعاء والتكامل (Execution Architecture)

تتم عملية تدوين السجلات بشكل فوري وغير مرئي للزائر عبر استدعاء طبقة الخدمة الخاصة بالتدقيق (`AuditService`):

```php
// استدعاء تسجيل حدث اتصال هاتفي في متحكم التفاصيل
public function trackCall(int $providerId) 
{
    $provider = $this->providerRepo->findById($providerId);
    if (!$provider) {
        return Response::json(['error' => 'Not Found'], 404);
    }
    
    $this->auditService->logContactEvent(
        $provider->id,
        $provider->primary_city_id,
        $provider->primary_service_id,
        'phone_call'
    );
    
    return Response::json(['success' => true]);
}
```
* **تنبيه تصميمي:** لا توجد لوحة تحليل إحصائية (Analytics Dashboard) معقدة في الإصدار الأول تلتزم بمبدأ YAGNI، ويتم تجميع البيانات وتهيئتها في جداول بسيطة ليتم تصفحها لاحقاً أو تصديرها كملفات CSV للمطورين عند الحاجة.
