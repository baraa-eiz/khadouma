# 18. Risks and Final Recommendations (المخاطر والتوصيات الفنية النهائية)

يقدم هذا المستند تحليلاً مفصلاً لأبرز المخاطر المعمارية التي تواجه مشروع منصة خدومة، مع تقديم التوصيات التقنية اللازمة للمرور بنجاح للمرحلة القادمة.

---

## 1. أبرز 5 مخاطر معمارية محتملة (Top Architectural Risks)

1. **إغراق النماذج بالرسائل الوهمية (Form Spamming & DoS):**
   * **الوصف:** نظراً لأن المنصة عامة ولا تفرض تسجيل حساب مستخدم للتقييم، فقد يقوم بعض المستخدمين أو المنافسين بإغراق قاعدة البيانات بتقييمات وهمية مكررة.
   * **الحل المعماري:** تفعيل محددات الطلب (Rate Limiting) على الـ IP مع تدقيق التقييمات عبر لوحة الإدارة بشكل صارم قبل النشر.
2. **تسريب وثائق الحوية الثبوتية (Identity Document Exposure):**
   * **الوصف:** خطر حفظ صور هويات الحرفيين والشهادات المهنية في مكان يمكن تخمينه أو الوصول إليه عبر الويب.
   * **الحل المعماري:** فرض عزل هذه الصور في المجلد المحمي `/storage/secure_uploads/` وتطبيق نظام الصلاحيات الإداري الثنائي عند استعراضها.
3. **تراكم الروابط التالفة (Broken SEO URLs):**
   * **الوصف:** قيام المشرفين بتغيير الأسماء التجارية للحرفيين بشكل مكرر مما يسبب تلف الروابط القديمة وفقدان الأرشفة في محركات البحث.
   * **الحل المعماري:** فرض الـ `public_id` الثابت في جميع الروابط، وتثبيت إعادة التوجيه التلقائي `301` للـ slugs المعدلة.
4. **ضعف أداء البحث مع تزايد الحرفيين (Query Performance Degradation):**
   * **الوصف:** استخدام فلاتر البحث والـ SQL LIKE بشكل متداخل ومكثف على استضافة ضعيفة قد يبطئ زمن استجابة السيرفر.
   * **الحل المعماري:** إضافة مؤشرات (Indexes) دقيقة على الجداول والخرائط، وتوفير واجهة موحدة للبحث لتسهيل الترقية مستقبلاً إلى FULLTEXT.
5. **تداخل الشفرات البرمجية وتلف المعمارية (Spaghetti Controllers):**
   * **الوصف:** استسهال إضافة منطق العمل داخل ملفات العرض (Views) أو المتحكمات مما يجعل كود المشروع صعب الصيانة والاختبار.
   * **الحل المعماري:** تشديد الالتزام بنظام الطبقات الأربع (Controller -> Service -> Repository -> View) وفرض مراجعة الكود البرمجي بانتظام.

## 2. ما يجب تأجيله وتجنب بنائه الآن (Postponed & Out of Scope)

لتفادي تشتيت موارد التطوير وللالتزام بمواعيد التدشين المحددة، يجب تأجيل وبتر العناصر التالية تماماً من النسخة الأولى (V1.0):
* **أنظمة الدفع والاشتراك الإلكتروني:** تتم المعاملات بين الزبون والحرفي يدوياً وبشكل مباشر دون وساطة مالية للمنصة.
* **نظام التموضع الجغرافي المباشر (GPS Maps):** نكتفي بالتوزيع الإداري للمناطق والأحياء، ونؤجل حسابات خطوط الطول والعرض وخريطة جوجل.
* **الدردشة الحية والاتصال الهاتفي عبر الإنترنت (VOIP/WebRTC):** التواصل يتم عبر شبكات الهاتف السورية العادية وتطبيق WhatsApp.
* **أنظمة المطابقة والتوجيه المعتمدة على الذكاء الاصطناعي (AI Matching):** يتم الاكتفاء بنظام فلاتر البحث البسيطة والتقييمات المعتمدة.
