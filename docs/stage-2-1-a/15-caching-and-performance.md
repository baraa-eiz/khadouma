# 15. Caching and Performance (إدارة التخزين المؤقت والسرعة)

يوضح هذا المستند استراتيجيات تحسين الأداء المطبقة لضمان سرعة تحميل فائقة وتلافي استهلاك موارد المعالج والذاكرة على الاستضافات الضعيفة والخوادم المشتركة.

---

## 1. التخزين المؤقت للخادم (Server-Side Performance)

### أ. تفعيل وتكوين OPcache (PHP OPcache)
* يعتبر تفعيل الـ OPcache الخطوة الأكثر تأثيراً على أداء PHP النظيفة، حيث يقوم بحفظ كود الـ Bytecode المترجم للملفات داخل الذاكرة العشوائية للسيرفر وتلافي قراءة وتفسير ملفات PHP مع كل طلب جديد.
* **إعدادات الإنتاج الموصى بها في `php.ini`:**
  ```ini
  opcache.enable=1
  opcache.memory_consumption=128
  opcache.interned_strings_buffer=8
  opcache.max_accelerated_files=10000
  opcache.validate_timestamps=0 ; في بيئة الإنتاج لمنع السيرفر من فحص تعديل الملفات مع كل طلب
  ```

### ب. الكاش المؤقت للملفات (Lightweight File Caching)
* لتفادي استدعاء استعلامات قاعدة البيانات المتكررة للصفحات الثابتة أو نتائج البحث العامة، نستخدم محرك كاش محلي بسيط يعتمد على نظام الملفات (File-based Cache).
* **آلية العمل:**
  * يتم توليد ملف كاش بصيغة نصية أو مصفوفة محولة (Serialized Array) داخل مجلد `/storage/cache/` بمدة صلاحية معينة (مثل 1 ساعة للصفحة الرئيسية).
  * في حال طلب الصفحة، يتحقق النظام من صلاحية الملف الفعلي؛ إن كان صالحاً، يتم قراءته وإرجاعه مباشرة للزائر خلال أجزاء من الملي ثانية ودون فتح أي اتصال بقاعدة البيانات.

---

## 2. تحسين سرعة العرض والتصفح (Front-End & Bandwidth Optimization)

* **تقليل حجم الصور:** يتم تحويل كافة الصور المرفوعة لصيغة WebP المضغوطة وتقييد أبعاد العرض (300 بكسل للصور المصغرة)، مما يوفر أكثر من 70% من استهلاك حزم البيانات (Bandwidth) مقارنة بصيغ PNG التقليدية.
* **الحد الأدنى من جافا سكربت (Vanilla JS Only):** يمنع تماماً استخدام أطر العمل الثقيلة مثل React أو Vue في الواجهة العامة للزوار. يتم معالجة النماذج وفلاتر البحث بجافا سكربت نقية خفيفة للغاية ولا تتجاوز بضعة كيلوبايتات لتلائم سرعات الجيل الثالث والرابع البطيئة لشبكات الهاتف المحمول في سوريا.
* **تخزين المتصفح للملفات الثابتة (Browser Cache Headers):** ضبط خادم الويب (Nginx/Apache) ليقوم بإضافة رؤوس الصلاحية الطويلة للملفات الثابتة (CSS, JS, Fonts):
  ```nginx
  # ضبط خادم Nginx للملفات الثابتة
  location ~* \.(css|js|webp|woff2)$ {
      expires 30d;
      add_header Cache-Control "public, no-transform";
  }
  ```
