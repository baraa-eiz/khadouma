# 02. Folder Structure (هيكل المجلدات والملفات)

يوضح هذا المستند التقسيم الهيكلي المعتمد لمجلدات المشروع، مع وضع حدود أمان صارمة بين ما هو عام وما هو خاص.

---

## 1. الهيكل العام للمشروع (Project Tree)

```text
/khadomeh
├── app/                      # المجلد البرمجي الرئيسي للمنصة (PHP Classes)
│   ├── Core/                 # فئات النظام الأساسية (Router, Database, Validator)
│   ├── Controllers/          # متحكمات معالجة الطلبات وإرجاع العروض
│   │   ├── Admin/            # متحكمات لوحة التحكم
│   │   └── Public/           # متحكمات الصفحات العامة والبحث
│   ├── Services/             # طبقة منطق العمل والعمليات
│   ├── Repositories/         # مستودعات جلب وحفظ البيانات (SQL Queries)
│   │   └── Interfaces/       # عقود الواجهات لتسهيل الاستبدال والاختبار
│   ├── DTO/                  # كائنات نقل البيانات (Data Transfer Objects)
│   ├── Helpers/              # وظائف مساعدة مخصصة (تطبيع، أمان، صور)
│   └── Middleware/           # مصافي الطلبات (تحقق المشرفين، فلاتر الحماية)
├── config/                   # ملفات إعدادات النظام وقاعدة البيانات
├── database/                 # سكربتات التهيئة وملفات التهجير والبيانات التجريبية
│   ├── migrations/           # ملفات التعديل والتحديث التدريجي للقاعدة
│   └── backups/              # النسخ الاحتياطية المجدولة
├── storage/                  # الملفات المخزنة محلياً خارج الويب
│   ├── secure_uploads/       # وثائق الهوية والشهادات الخاصة بالحرفيين
│   ├── logs/                 # سجلات أخطاء السيرفر وسجلات الأمان
│   └── cache/                # ملفات الكاش المؤقتة
├── views/                    # قوالب العرض الرسومية (PHP Templates)
│   ├── admin/                # قوالب لوحة التحكم
│   ├── public/               # قوالب الموقع العام والبحث
│   ├── layouts/              # الهياكل المشتركة (Header, Footer, Menu)
│   └── components/           # عناصر الواجهة الصغيرة القابلة لإعادة الاستخدام
├── docs/                     # التوثيق الفني للمشروع
└── public/                   # المجلد الوحيد المتاح للعامة عبر الويب (Web Root)
    ├── assets/               # الملفات الثابتة المجمعة
    │   ├── css/              # ملفات التنسيق والمظهر
    │   ├── js/               # سكربتات جافا سكربت الخفيفة
    │   └── images/           # أيقونات الموقع الثابتة
    ├── uploads-public/       # الصور العامة المصرح بزيارتها (صور الحرفيين والورش)
    │   ├── avatars/          # صور الحرفيين الشخصية
    │   └── galleries/        # صور أعمال الحرفيين
    └── index.php             # نقطة الدخول البرمجية الموحدة للمنصة
```

## 2. تفاصيل وتوصيف المجلدات (Directory Description)

* **`/app`**: يضم جميع كائنات البرمجة كائنية التوجه (OOP) للمنصة تحت نطاق التسمية `App\`. يتم تحميله تلقائياً بواسطة Autoloader مدمج متوافق مع PSR-4.
* **`/config`**: يحتوي على ملفات التكوين الحساسة (إعدادات قاعدة البيانات، مفتاح التشفير، إعدادات البريد والرسائل).
* **`/database`**: يحتوي على ملفات الـ SQL وجداول التحديثات المرجعية لضمان بقاء خوادم XAMPP وبيئة VPS متطابقتين برمجياً.
* **`/storage`**: مجلد محمي تماماً يحتوي على سجلات الأحداث وصور الهوية التي يرفعها الحرفيون للتأكيد.
* **`/views`**: يفصل الـ HTML والـ CSS تماماً عن المنطق البرمجي، بحيث يتم تمرير البيانات إليها على شكل متغيرات نقية فقط.
* **`/public`**: المجلد الخارجي. يجب ضبط خادم الويب (Apache/Nginx) ليشير إليه كـ `DocumentRoot`.

---

## 3. محظورات المجلد العام (Security Prohibitions)

يمنع منعاً باتاً وضع أي من الملفات التالية داخل مجلد `/public/`:
1. **ملفات الإعدادات البرمجية (`.env` أو ملفات الإعدادات في `/config`)**.
2. **الشهادات الرقمية والمفاتيح الخاصة والوثائق الثبوتية الخاصة بالحرفيين**.
3. **ملفات قاعدة البيانات وسجل العمليات ونصوص الـ SQL**.
4. **سجلات النظام ومخرجات الأخطاء وتتبع الخادم (`logs`)**.
5. **شفرة المصدر المباشرة ومستودعات الأكواد للطبقات الداخلية**.
