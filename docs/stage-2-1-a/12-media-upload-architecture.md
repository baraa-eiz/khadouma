# 12. Media Upload Architecture (معمارية رفع ومعالجة الوسائط)

يوضح هذا المستند دورة حياة معالجة الملفات والصور المرفوعة في منصة خدومة لضمان الأداء الأقصى وأمن البيانات.

---

## 1. تصنيف مجلدات تخزين الوسائط (Storage Partitioning)

تقسم ملفات الوسائط المرفوعة بناءً على طبيعتها وأمنها إلى قسمين أساسيين:

### أ. الوسائط العامة (Public Media Root)
* **الموقع:** `/public/uploads-public/`
* **المحتويات:**
  * `avatars/`: صور الحرفيين الشخصية.
  * `galleries/`: صور أعمال الحرفيين وسجل ورشهم.
* **شروط الوصول:** متاحة للتصفح العام والمباشر من متصفح الزوار لتقليل الضغط على السيرفر وسرعة العرض.

### ب. الوسائط الخاصة والمحمية (Private Media Root)
* **الموقع:** `/storage/secure_uploads/`
* **المحتويات:**
  * `identity_proofs/`: صور الهوية الوطنية وجوازات السفر.
  * `certificates/`: شهادات الخبرة والتأهيل المهني للحرفي.
* **شروط الوصول:** محمي تماماً خلف مجلد الويب. لا يمكن الوصول إليه إلا عبر فئة متحكم يملك فلتر أمان وجلسة مشرف نشطة.

---

## 2. معالجة وتعديل الصور (WebP Conversion & EXIF Stripping)

لتقليص حجم الملفات لتناسب سرعات الإنترنت الضعيفة في سوريا وحماية خصوصية المستخدمين، تمر كل صورة مرفوعة بالعمليات التالية فور استلامها:

1. **إزالة بيانات الميتا (EXIF Metadata Stripping):**
   * إزالة إحداثيات GPS الجغرافية، ونوع الهاتف، وتاريخ الالتقاط لحماية خصوصية الحرفيين قبل حفظ الصورة.
2. **التحويل إلى صيغة WebP:**
   * يتم استخدام مكتبة `GD` الافتراضية في PHP لتحويل كافة الصور (PNG/JPEG) إلى صيغة `WebP` المضغوطة ذات الحجم الصغير والجودة العالية.
3. **توليد النسخ المصغرة (Thumbnails):**
   * يتم توليد نسختين لكل صورة مرفوعة في المعرض العام:
     * **النسخة الكاملة المعالجة (Full):** بعرض لا يتجاوز 1200 بكسل وجودة 80% (كحد أقصى).
     * **النسخة المصغرة (Thumbnail):** بعرض 300 بكسل وجودة 70% لاستخدامها في بطاقات الحرفيين وقوائم البحث لتسريع زمن التحميل الأولي للموقع.

---

## 3. تسمية وحفظ الملفات (Naming & Folder Strategy)

* لتجنب حدوث تصادم أو استبدال للملفات التي تحمل نفس الاسم، ولتجنب وجود آلاف الملفات في مجلد واحد (مما يبطئ نظام الملفات في السيرفر)، تتبع التسمية الهيكل التالي:
  * يتم توليد اسم فريد باستخدام التوقيع الزمني مع كود عشوائي مشفر: `[sha1_hash(time() + rand())].webp`.
  * يتم توزيع الملفات في مجلدات فرعية بناءً على تاريخ الرفع (السنة/الشهر): `/uploads-public/galleries/YYYY/MM/filename.webp`.

---

## 4. شروط وإجراءات التحقق من الملفات (File Upload Validation)

تطبق الدالة المساعدة للرفع الشروط التالية بشكل متسلسل ومستقل:
* **التحقق من الامتداد الفعلي (Mime Type Check):** قراءة محتوى الملف باستخدام دالة `finfo_file()` لمطابقة المحتوى الفعلي وتلافي خداع الامتدادات الظاهرية.
* **الحد الأقصى للحجم:** رفض أي ملف يتجاوز 5 ميغابايت وإعادة رسالة واضحة للمستخدم.
* **استخدام المعامل المساعد:**
  ```php
  // دالة مصغرة تمثل نمط المعالجة المعتمد
  $uploadedFile = $_FILES['avatar'];
  $mediaService = new MediaService();
  
  try {
      $avatarUrl = $mediaService->uploadPublicImage($uploadedFile, 'avatar');
      // يتم حفظ الرابط الجديد في جدول الحرفي
  } catch (UploadException $e) {
      $_SESSION['flash']['errors'] = [$e->getMessage()];
      redirectBack();
  }
  ```
