# 10. DTO and Data Validation (كائنات نقل البيانات والتحقق من الحقول)

يوضح هذا المستند كيفية تدقيق المدخلات وحقن البيانات بشكل آمن بين طبقات التطبيق باستخدام كائنات مبسطة لنقل البيانات (DTOs) ومدقق مستقل.

---

## 1. كائنات نقل البيانات (Data Transfer Objects - DTOs)

تمنع كائنات الـ DTO فوضى تمرير المصفوفات المفتوحة (Associative Arrays) بين المتحكمات والخدمات، مما يضمن وجود هيكل بيانات واضح وموثق برمجياً.

### أمثلة الكائنات المعتمدة:
1. **`ProviderData`**: يحمل بيانات تسجيل وتحديث الحرفي (الاسم، الهاتف، السيرة، الخدمات المختارة، المناطق الجغرافية).
2. **`ReviewData`**: يحمل بيانات تقييم العملاء الجدد (اسم العميل، التقييم الرقمي، النص التعليقي، معرّف الحرفي).
3. **`ReportData`**: يحمل بيانات البلاغات (اسم المبلّغ، هاتفه، معرّف الحرفي المشكو منه، السبب والتفاصيل).
4. **`AdminLoginData`**: يحمل البريد الإلكتروني وكلمة المرور للمشرف عند محاولة تسجيل الدخول.

---

## 2. قواعد التحقق ومعايير السلامة (Validation Rules)

يخضع كل حقل مدخل عبر النماذج العامة لشروط تحقق صارمة قبل معالجته:

### أ. أرقام الهواتف (Phone Normalization)
يجب أن تتطابق أرقام الهواتف المدخلة للحرفيين مع الشبكات السورية المتاحة (سيريتل، MTN، الهواتف الأرضية).
* **الشروط:**
  * يجب أن يبدأ الرقم بـ `09` ويتبعه 8 أرقام (للهواتف المحمولة)، أو يبدأ برمز المحافظة (مثل `011` لدمشق) ويتبعه 7 أرقام (للهواتف الأرضية).
  * يقبل النظام الصيغة الدولية `+963` ويقوم بتطهيرها وتحويلها إلى الصيغة المحلية الموحدة للربط بـ WhatsApp بسهولة.

### ب. التقييمات الرقمية (Review Ratings)
* **الشروط:**
  * يجب أن يكون التقييم رقماً صحيحاً حصراً بين 1 (ضعيف جداً) و 5 (ممتاز).
  * يجب ألا يحتوي حقل التعليق على روابط خارجية أو أكواد برمجة (XSS prevention).

### ج. معايير سلامة الرفع والملفات (File Upload Validation)
* **الشروط:**
  * **النوع المسموح (Mime Type):** صور فقط (`image/jpeg`, `image/png`, `image/webp`).
  * **الحجم الأقصى:** 5 ميغابايت للملف الواحد.
  * **الحماية من الثغرات:** يتم قراءة ترويسة الملف والتحقق من أبعاد الصورة الفعلي لمنع رفع ملفات تنفيذية وهمية متخفية بصيغة صور (e.g., `backdoor.png.php`).

## 3. تطبيق عملي للتحقق (Sample Execution flow)

```php
// نموذج تدقيق المدخلات في المتحكم
public function storeReview() 
{
    $validator = new Validator($_POST);
    
    $validator->required(['provider_id', 'client_name', 'rating']);
    $validator->integer('rating')->between(1, 5);
    $validator->maxLength('client_name', 100);
    $validator->maxLength('comment_text', 1000);
    
    if (!$validator->isValid()) {
        // حفظ الأخطاء وإعادة التوجيه للخلف
        $_SESSION['flash']['errors'] = $validator->getErrors();
        redirectBack();
    }
    
    // تحويل البيانات لكائن DTO وتمريرها للخدمة
    $dto = ReviewData::fromArray($validator->getCleanData());
    $this->reviewService->submit($dto);
    
    $_SESSION['flash']['success'] = 'شكراً لك، تم إرسال تقييمك بنجاح وهو بانتظار موافقة الإدارة.';
    redirect('/damascus/plumbing/abu-ahmad-p8kf2');
}
```
